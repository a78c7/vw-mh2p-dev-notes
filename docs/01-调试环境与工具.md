# 01 调试环境与工具

[← 目录](../README.md)

## 1. SSH 进车机

- 用 ModKit 刷入 [fifthBro/mh2p-ssh-access](https://github.com/fifthBro/mh2p-ssh-access)（SSH 模块，配合指定的 USB 网卡 D-Link DUB-E100）。车机地址 172.16.250.248（出厂默认），端口 2012。
- macOS 没有 AX88772C（D-Link DUB-E100）的驱动 → 写了一个用户态驱动 [`tools/axbridge/axbridge.c`](https://github.com/a78c7/touareg-cn-carplay-mods/tree/main/tools/axbridge)（libusb + utun，自己回 ARP），`sudo ./axbridge` 即可，实测 100M、延迟 2 ms。
- 坑：**有线 CarPlay 会切断 USB 网卡供电**，调试时请用无线 CarPlay。

## 2. 交叉编译

- 用 clang（`--target=armv7a-none-eabi -mthumb -mfloat-abi=softfp`）+ GNU ld，sysroot 用 [luka-dev/qnx65-armv7-toolchain](https://github.com/luka-dev/qnx65-armv7-toolchain)。车机实际是 QNX **6.6**，6.5 的 sysroot 也能用。
- 坑 1：QNX 6.6 的 libc 没有 `__aeabi_memcpy/memclr/ul2d`（clang 会生成）→ 自带一个 `aeabi_shim.h`。
- 坑 2：lld 链接的 .so 在车机上 `dlsym(RTLD_NEXT)` 返回 NULL（钩子拿不到原函数 → CarPlay 连不上）；只用 sysv hash 则根本加载不了。改用 GNU ld `--hash-style=both` 解决。**【MH2p 通用】**
- 坑 3：链接用到 screen/EGL 的程序时不能用 `--unresolved-symbols=ignore-all`（这些函数会被链成地址 0 → 一调用就崩），要用同 soname 的桩库（`libscreen.so.1` 等，只导出用到的函数名）让 ld 生成 PLT。
- 坑 4：`isnan`、`lrint` 会引入 QNX 上的 `_LDclass` 等额外导入，自己实现更省事。
- 习惯：每次构建用带版本号的新文件名，传到车上后核对 md5，避免"改了没效果"其实跑的是旧文件。
- 车上没有 nohup：后台运行用 `(trap "" HUP; exec 程序 </dev/null >log 2>&1) &`。

## 3. 车机 Java（J9）程序

- 主界面程序 `/ifs/lsd.jxe` 用 [luka-dev/jxe2jar](https://github.com/luka-dev/jxe2jar) 转成普通 jar（约 4 分钟，4.7 万个类，类名没有混淆），再用 CFR 反编译阅读。国行皮肤的界面在 `skin3/viewhandler.zip` 里（1246 个 jxe）。
- 编译自己的插件：JDK 8 `javac -source 1.4 -target 1.4`，`-bootclasspath` 用转换出来的 `lsd.jar`（或 J9 的 `jcl.jar`）。**class 版本必须 ≤ 48**，见 [02 篇](02-CarPlay导航上HUD.md)。
- 可复现构建：用同样的方法重新编译出来的二进制与车上运行的版本逐字节一致。

## 4. dmdt：车机自带的显示管理调试工具

`/eso/bin/apps/dmdt`，非常有用。**【MH2p 通用】**

- 需要在一个有 `./config -> /etc/eso/production` 的目录里运行，并且要终端（`ssh -tt`），否则输出会丢。
- `dmdt gd` 列出所有 displayable；`dmdt gs` 看每块屏当前显示哪些。
- `dmdt sd 4 58 33` 设置仪表（display 4）的显示列表。
- `dmdt ts 4 /tmp/a.png` 截取仪表画面。需要 `LD_LIBRARY_PATH=/mnt/app/armle/lib:/mnt/app/armle/usr/lib:/mnt/app/armle/graphics:/eso/lib:/lib:/usr/lib`；命令返回后文件还在写，等 2～3 秒再取，否则 PNG 不完整。
- 截到的是**车机发给仪表的画面**，不含仪表自己画的时钟、指针、提示框、挡位框。要定位这些元素只能拍照（见 [03 篇](03-CarPlay地图上仪表.md) 第 13 节）。

## 5. 其它常用操作

- 远程重启车机：`echo gem-reset > /dev/ooc/system`（ModKit 用的方法）。
- 只重启 CarPlay 进程：`slay dio_manager`（会自动拉起，iPhone 自动重连）。
- 用 `screen_read_display` 抓物理屏：[`tools/screen/scrcap.c`](https://github.com/a78c7/touareg-cn-carplay-mods/tree/main/tools)。
- 查防火墙规则：`pfctl -sr`。

## 6. 车机 shell 的坑

- `/tmp` 不能建子目录，也**不支持 rename / link**（`mv`、`ln` 报 Function not implemented）。写文件要直接覆盖，读端只取以换行结尾的完整行。**【MH2p 通用】**
- 没有 `sed`、`strings`、`which`、`uptime`；`grep` 不支持 `\|`。
- `/mnt/app` 开机是只读，写之前 `mount -uw /mnt/app`。
- CarPlay 进程（dio_manager）里的钩子会从 root 降权为 uid 1037（carplay）：root 建的文件它删不掉、改不了。需要它读写的文件要提前设好权限，或者干脆设计成"按修改时间/内容触发、从不删除"。
