# 06 给其他车型的建议

[← 目录](../README.md)

换一台 MH2p 车，按这个顺序先摸清情况，再决定能直接复用什么。据 [MH2p SD ModKit 网站](https://lawpaul.github.io/MH2p_SD_ModKit_Site/) 的列表，同平台的有大众途锐、奥迪（MIB2+ High：A1/A6/A7/A8/Q3/Q7/Q8/e-tron）、保时捷（PCM 5：911 992、Cayenne E3、Macan 95B、Panamera 976）、兰博基尼 Urus（LIS III）。下面的内容只在途锐上验证过：

1. **确认车机版本**：服务菜单或 ModKit 日志里的版本号（如 `MH2p_CN_VWG36_P2878`）。U 盘包只认途锐 P2878，别的版本会自动退出。
2. **先装 SSH**（[01 篇](01-调试环境与工具.md)）。没有 SSH 只能靠 U 盘收日志，一轮要十几分钟，效率差很多。
3. **看显示结构**：`dmdt gd` / `dmdt gs` 看仪表是哪个 display、原车地图是哪个编号（途锐是 33）、有哪些用不到的空闲编号（途锐用 58）。
4. **看防火墙**：`pfctl -sr`，接收第二路视频的端口必须是放行的。
5. **看 libairplay**：版本号和导出符号，确认屏幕流加密方式（[03 篇](03-CarPlay地图上仪表.md) 第 3 节）和 `session` 里配对会话指针的偏移。
6. **反编译 lsd.jxe**：
   - 导航上 HUD：找 BAP NavSD 读的 datapool / list 编号（途锐 732、741、744、751、838）。
   - 仪表地图：搜 `showDisplayables`、`switchContext`、`SwitchToPermanentMapSequence`，看原车怎么切仪表地图。
   - 信息框：看 `DSICarVehicleStates`、`DSICarKombi` 哪些属性可用，先做只读探针实测。
7. **Java 插件**：class 版本一定 ≤ 48；在 `bundles.properties` 的 Lateload 最后注册。
8. **车标位置**：仪表尺寸、时钟位置不同就要重新校准安全区，用照片定位仪表自绘元素。

## 换品牌时要特别注意的

- **界面皮肤不一样**：途锐国行的界面在 `skin3/viewhandler.zip`。奥迪、保时捷、兰博基尼各有自己的皮肤和布局，全屏 CarPlay 的补丁（改哪个文件、哪几个字节）要按自己车的皮肤重新找，不能照搬途锐的补丁表。找法相同：在皮肤里搜 CarPlay 视图的尺寸。
- **仪表不一样**：奥迪的虚拟座舱、保时捷和兰博基尼的仪表，尺寸、显示编号、哪些区域是仪表自己画的都不同。`dmdt gd/gs` 和拍照这两步一定要重新做。仪表地图能不能放进去，先看原车有没有"仪表显示导航地图"这个功能：途锐的方案是借用原车地图的位置（编号 33）叠在上面，原车没有这个位置就得另想办法。
- **HUD**：途锐的 HUD 数据走 BAP NavSD，datapool / list 编号在 `lsd.jxe` 里找。别的品牌 HUD 显示的内容和协议可能不同，先看原车导航时 HUD 显示什么。
- **车辆数据**：`DSICarVehicleStates`、`DSICarKombi` 是集团通用的接口名，大概率都有，但**哪些项可用、单位、无效值**每辆车不同（比如途锐增压一直是 0）。先做只读探针（04 篇第 2 节），别直接照搬途锐的项目表。性能车的最大功率、扭矩、G 值范围也更大，合理范围上限要放宽。
- **Java 插件**：`lsd.jxe` 和 OSGi 插件机制是平台共用的，class 版本 ≤ 48、在 `bundles.properties` 注册这些规则应该一样；没有导出的 `lsd.jar` 也可以用桩类编译（01 篇第 7 节），但前提是有一个已经引用了所需类的 jar。
- **固件版本**：同一品牌不同固件版本，库的版本和偏移也会变（libairplay 的会话指针偏移、补丁偏移），升级固件后要重新核对。

能直接复用的：钩子注入方式、ChaCha20 解密（同版本 libairplay）、`[58, 33]` 叠放思路、冷启动和断开恢复的处理、`/tmp` 的各种限制。需要重新找的：编号、端口、datapool 编号、补丁偏移、坐标、可用的车辆数据项。另外时钟每次开机从 1970 开始、`/tmp` 每次开机清空、无效值是 -3276.5 这类哨兵数（01 篇第 8 节），这些平台层面的坑大概率一样。

有问题欢迎在 [改装仓库](https://github.com/a78c7/touareg-cn-carplay-mods/issues) 提 Issue。
