# R3 车辆数据接口（DSI）

[← 平台参考](README.md)

车机通过网关能收到大量车辆数据，HMI 里用 DSI 接口订阅（用法见 [R2](R2-HMI-J9-Java.md) 第 5 节）。下面是途锐 3.0T 上实测的结果。**哪些项可用、单位、无效值每台车都可能不同**，换车型一定先做只读探针：只订阅、只记日志，不写任何东西。

通用规则：【MH2p 通用】

- 每个数据组都有一个对应的 ViewOptions，里面每项的 state：**0 = 没有这项，1 = 装了但当前无效，2 = 可用**。
- 回调的有效标志是 `1` 才用。
- 无效值不会单独标出来，而是一个固定的"哨兵"数（见各表），必须过滤。

## 1. DSICarVehicleStates

| 属性 | 内容 |
| --- | --- |
| 12 | 高频数据的 ViewOptions |
| 13 | 中频数据的 ViewOptions |
| 14 | 高频数据 `DynamicVehicleInfoHighFrequent` |
| 15 | 中频数据 `DynamicVehicleInfoMidFrequent` |
| 16 | 半静态数据的 ViewOptions |
| 17 | 半静态数据 `SemiStaticVehicleData` |

### 高频（属性 14）

刷新率：着车 8～10 次/秒，熄火约 3 次/秒（可能只在变化时发）。【途锐实测】

| 字段 | 单位 / 含义 | 途锐实测 |
| --- | --- | --- |
| `vehicleSpeed` | 表显车速，km/h（整数） | 可用。比真实车速高几个百分点 |
| `realVehicleSpeed` | 真实车速，km/h（结构同 `CarBCSpeed`） | 可用。桩类里没有，反射读 |
| `engineSpeed` | 转速 rpm | 可用。怠速约 660 |
| `currentOutputPower` | 功率 kW | 可用 |
| `currentTorque` | 扭矩 Nm | 可用。ECU 估算值，不是传感器测的；功率 = 扭矩 × 转速 ÷ 9549，每一行都吻合 |
| `longitudinalAcceleration` | 纵向加速度 **m/s²**（步长 0.16） | 可用。起步 +3.2、刹车 −5.12 |
| `lateralAcceleration` | 横向加速度 **g** | 可用。和横摆角速度 × 车速推算一致；原车运动显示的代码也只把纵向除以 9.81 |
| `acceleratorPosition` | 油门开度 % | 可用 |
| `brakePressure` | 制动压力，约 bar | 可用 |
| `wheelAngle` | 方向盘转角 ° | 可用 |
| `yawRate` | 横摆角速度 °/s | 可用。反射读 |
| `espWheelVelocityFrontLeft` / `FrontRight` / `RearLeft` / `RearRight` | 四轮轮速 km/h | 可用。极低速时一直读 0（起步后第一个非零值已有好几 km/h） |
| `espOversteering` / `espUndersteering` | ESP 过度 / 不足转向 | state 2，数值没分析 |
| `absChargingAirPressure` | 增压（绝对） | state 2，但一直是 0 |
| `relChargingAirPressure` | 增压（相对） | 最大见过 40，单位不明 |
| `powermeter` | 功率表 | state 0；值 4093 = 无效 |
| `allWheelDriveTorque`、`relAllWheelDriveTorque`、`torqueDistribution*` | 四驱扭矩、四轮扭矩分配 | state 0，没有 |
| `shiftLight` | 换挡提示灯 | state 1（装了但无效） |

### 中频（属性 15）

只在数值变化时发。【途锐实测】

| 字段 | 单位 / 含义 | 途锐实测 |
| --- | --- | --- |
| `gearboxOilTemperature` | 变速箱油温 °C | 可用 |
| `automaticGearShiftTransMode` | 换挡杆位置 | 见过 1～5，对应关系没核对 |
| `currentGear` | 挡位 | 行驶中只见过 0、1、2，**不是**实际挡位号，含义待查 |
| `acceleratorKickDown`、`driverIsBraking`、`aCCIsActive` | 强制降挡、是否在刹车、ACC 是否开启 | 有回调，没细看 |
| 车门、安全带等 | | 有回调，没细看 |

### 半静态（属性 17）

| 字段 | 途锐 3.0T 报的值 |
| --- | --- |
| `maxOutputPower` | 265 kW |
| `maxTorque` | 450 Nm |
| `maxChargingAirPressure` | 2.5 bar |

### 扭矩口径（途锐实测）

- 厂家公布的扭矩按国标（GB/T 17692）在发动机台架上测，是曲轴端的。车机报的扭矩和它同一端，可以直接比。
- 油门 68% 加速时，2700～3800 rpm 扭矩稳定在 450～460 Nm、持续约 3 秒，比额定 450 Nm 略高。原因可能是估算误差、短时超增压，或者是没扣摩擦损失的"内部扭矩"口径，接口里没写，要靠大油门记录判断。

## 2. DSICarKombi（行车电脑）

| 属性 | 回调 | 内容 | 途锐实测 |
| --- | --- | --- | --- |
| 4 | ViewOptions | 各项是否可用 | |
| 6 | `updateBCCurrentConsumption1` | 当前消耗（值 + 单位码） | 单位码 0 = L/100km，2 = L/h（停车时自动切换）；停车时偶尔报 **32770** = 无效 |
| 8 | `updateBCCurrentRange1` | 续驶里程 km | 可用 |
| 11 | `updateBCShortTermAverageConsumption1` | 自启动起平均消耗 | 可用 |
| 13 | `updateBCShortTermGeneral` | 自启动起：里程、平均车速、行驶时间 | 可用 |
| 17 | `updateBCCycleAverageConsumption1` | 自上次加油起平均消耗 | 可用 |
| 19 | `updateBCCycleGeneral` | 自上次加油起：里程、平均车速、行驶时间 | 可用 |
| 14 | `updateBCLongTermAverageConsumption1` | 累计平均消耗 | 可用 |
| 16 | `updateBCLongTermGeneral` | 累计：里程、平均车速、行驶时间 | 可用 |
| 23 | `updateBCTankLevel1` | 油量，**只有百分比** 0～100 | 升数要自己乘油箱容积（途锐 90 L） |
| 63 | `updateBCCoolantTemperature` | 冷却液温度 | 热车后一直 90°C |
| 64 | `updateBCOilTemperatureValue` | 机油温度 | 冷车时 state ≠ 1、值 **−3276.5** |
| 65 | `updateBCOutsideTemperature` | 车外温度 | 同上，要过滤 −3276.5 |

- 三个存储器（自启动起 = ShortTerm，自上次加油起 = Cycle，累计 = LongTerm）就是原车"行驶数据"页的三页，数值已和原车核对一致。三个 General 结构相同：里程 `CarBCDistance`、平均车速 `CarBCSpeed`、行驶时间 `CarBCTime`（分钟）。【途锐实测】
- 温度结构里有 `temperatureValue`、`temperatureUnit`、`state`。原车在机油到约 60°C 前不显示机油温度，对应的就是 state ≠ 1 这段时间。【途锐实测】
- 单位码 1（推测 km/L）没见过。【未验证】

## 3. 车上看不到的数据

- 增压（实测为 0）、点火角、爆震、空燃比、进气温度这些 ECU 内部数据，DSI 里没有。要用诊断工具读。【途锐实测】
- 原车仪表上的 G 值小窗口动画是仪表自己画的，车机改不了。【途锐实测】
