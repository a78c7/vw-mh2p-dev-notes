## 标注

每条都标了来源和适用范围：

- **【途锐实测】**：在 2023 款国行途锐 `MH2p_CN_VWG36_P2878` 上实际验证过。
- **【MH2p 通用】**：平台层面的东西（QNX、J9、DSI、libairplay、displaymanager），同平台的大众、奥迪、保时捷、兰博基尼车机大概率一样，但只在途锐上验证过。
- **【未验证】**：从程序里读到、还没在车上实测，或只是推测。

奥迪、保时捷、兰博基尼车主如果实测了自己的车，欢迎在 [Issue](https://github.com/a78c7/touareg-cn-carplay-mods/issues) 里补充，会加上车型标注。

## 这里不写什么

- **不放大众的任何文件**：反编译出来的源码、jar、固件、界面文件都不放。只用自己的话描述结构和编号。
- **不涉及任何保护机制的绕过**：防盗、部件保护（Component Protection）、按需付费功能（FEC / SWaP）的激活、签名校验、别人软件的授权绑定，一概不写。
- **不写安全漏洞**。

研究依据是《计算机软件保护条例》第十七条："为了学习和研究软件内含的设计思想和原理，通过安装、显示、传输或者存储软件等方式使用软件的，可以不经软件著作权人许可，不向其支付报酬。"本仓库只记录研究得出的结构和方法。
